{% trans "Why the carton is not part of the item ID" %}

{% trans "The first proposal was:" %} 01DCJM-TJM3-1-CTN-001/057

  • {% trans "“CTN-001” inside the item ID becomes wrong the moment the item is moved to another carton, so the label would have to be reprinted or would mislead." %}
  • {% trans "“/057” becomes wrong when a carton is added or removed; “/” also breaks file names, web addresses and Excel (which turns 1/57 into a date)." %}
  • {% trans "Two digits for the unit number stop at 99." %}
  • {% trans "“TJM3-1” repeats information the system already knows." %}
{% blocktrans %}Instead, the location is a record: scanning DCJM-017 shows CTN-003 › PLT-001 › CNT-001, and the history shows it was moved from CTN-002 during export inspection. “Carton 17 of 57” is still printed on the carton label as a shipping mark, but it is not part of the ID.{% endblocktrans %}
